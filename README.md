I wanted to create a 2d visualization of the bands that I like in order to see which ones were most similar based on listening experience, rather than genre.
So, I evaluated a bunch of my favorite bands based on a number of genre-independent categories, and then used SVD to reduce these multidimensional data points to 2d space.
The result is a map where the proximity of two musicians/bands shows how similar their music is. The most notable conclusion is that while genre is a useful tool to categorize music, it should not be the only tool. 
My map shows that many of the most similar bands to each other are from completely different genres, time periods, and backgrounds.
This is peronsally how I like to listen and discover new music. It allows you to find new music that might have a similar emotional impact on you as another artist you like, but do so in a completely different way and with different sounds/instruments. 
You can run the program and use the web app to not only just view the map, but also use the recommendation feature to find new music to listen to!
